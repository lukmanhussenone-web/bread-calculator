# Bread Carton Calculator

A responsive web app for planning bakery packing. Add bread types, enter units, and customize units per carton to see full carton counts and leftover units instantly.

## Starter bread types

The packing list starts with these products, each set to 1 unit:

| Bread type | Units per carton |
| --- | ---: |
| Any Time Bread | 44 |
| S Bread | 80 |
| Banana Bread | 16 |
| Sandwich Bread | 16 |
| Morning Bread | 60 |
| Fruit Bread | 24 |
| White Bread | 29 |
| XL Bread | 24 |

You can change quantities and carton sizes, add or remove products, and the list is saved in browser local storage.

## Run it

Open `index.html` in a browser. No installation or build step is required.

## Features

- Eight bread types preloaded with customizable carton sizes
- Add and remove multiple bread types
- Instantly calculate cartons and leftovers per product and across the packing list
- Keep your list between visits with browser local storage
- Responsive layout for desktop and mobile
