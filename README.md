# Bread Carton Calculator

A small responsive web app for planning bakery packing. Add bread types, enter units and customize units per carton to see full carton counts and leftover units instantly. Your packing list is saved in this browser on this device.

## Run it

Open `index.html` in a browser. No installation or build step is required.

## Features

- Add and remove multiple bread types
- Set a different carton capacity for each type
- Instantly calculate cartons and leftovers per product and across the packing list
- Keep your list between visits with browser local storage
- Responsive layout for desktop and mobile
